# NextStep — Tech Stack

## Tech Stack Wajib

NextStep menggunakan kombinasi teknologi yang telah ditentukan dalam SOP internship.

Stack ini bersifat **terkunci (mandatory)** untuk memastikan proses development lebih konsisten, memudahkan mentor dalam membantu proses debugging, serta membuat penggunaan AI coding assistant lebih akurat.

| Bagian     | Teknologi Wajib                             | Penjelasan                                                                              |
| ---------- | ------------------------------------------- | --------------------------------------------------------------------------------------- |
| Framework  | **Next.js**                                 | Framework utama untuk membangun aplikasi web secara cepat dan terstruktur.              |
| Library UI | **React**                                   | Library untuk membangun komponen antarmuka yang interaktif dan reusable.                |
| Bahasa     | **TypeScript**                              | Bahasa pemrograman yang memberikan type safety untuk membantu mengurangi error dan bug. |
| Styling    | **Tailwind CSS**                            | Utility-first CSS framework untuk membangun tampilan secara cepat dan konsisten.        |
| Database   | **PostgreSQL** — via **Supabase atau Neon** | Database relasional untuk menyimpan dan mengelola data aplikasi secara terstruktur.     |

## Important Constraint

Tech stack di atas **tidak boleh diganti** dengan teknologi lain tanpa persetujuan mentor.

Pengembangan NextStep pada tahap selanjutnya harus tetap menggunakan:

**Next.js + React + TypeScript + Tailwind CSS + PostgreSQL (Supabase/Neon)**
