# NextStep — User Flow

**Product:** NextStep
**Tagline:** *Know what you want. Know what to do.*

---

Alur utama NextStep:

```text

      ↓

      ↓
```

## 2. Detailed Flow

### Step 1 — Landing Page

Pengguna masuk ke halaman utama NextStep dan memahami bahwa aplikasi membantu mereka mengetahui apa yang ingin dilakukan dan langkah yang harus diambil.

**Action:**

User memilih untuk mulai menggunakan NextStep.

↓

### Step 2 — Tell What's on Your Mind

Pengguna menceritakan kondisi, masalah, keinginan, atau pikirannya.

Input dapat dilakukan melalui:

* Text
* Voice

↓

### Step 3 — AI Understands Context

AI menganalisis input pengguna untuk memahami:

* Situasi pengguna
* Masalah atau kebutuhan
* Intent pengguna
* Kemungkinan tujuan yang ingin dicapai

↓

### Step 4 — Goal Clarity Check

NextStep menentukan apakah tujuan pengguna sudah cukup jelas.

**Jika tujuan belum jelas:**

AI mengajukan pertanyaan untuk membantu pengguna memperjelas apa yang sebenarnya ingin dicapai.

↓

User menjawab pertanyaan.

↓

AI kembali memahami jawaban dan membantu memperjelas goal.

**Jika tujuan sudah jelas:**

Pengguna dapat mengonfirmasi goal.

↓

### Step 5 — Goal

Setelah proses klarifikasi selesai, pengguna memiliki tujuan yang lebih jelas.

Contoh:

> **Goal:** Learn AI fundamentals.

↓

### Step 6 — Action Plan

NextStep membuat rencana tindakan berdasarkan goal pengguna.

Contoh:

```text
Goal:
Learn AI fundamentals

Action Plan:
1. Learn Python basics
2. Learn basic mathematics for AI
3. Learn machine learning fundamentals
4. Build a simple ML project
```

↓

### Step 7 — What Should I Do Next?

NextStep menentukan langkah konkret yang perlu dilakukan pengguna saat ini.

Contoh:

> **What Should I Do Next?**
> Pelajari dasar Python selama 30 menit.

↓

### Step 8 — Progress Tracking

Pengguna dapat melihat perkembangan dari action plan yang telah dibuat.

Progress diperbarui berdasarkan langkah yang telah diselesaikan.

## 3. Example User Journey

### User Input

> "Aku bingung mau fokus belajar apa. Aku tertarik AI, cybersecurity, dan web development, tapi aku pengen punya skill yang berguna buat karier."

### AI Understanding

NextStep memahami bahwa pengguna:

* Memiliki beberapa bidang yang diminati.
* Belum menentukan fokus utama.
* Ingin membangun skill untuk karier.

### Goal Clarification

AI mengajukan pertanyaan untuk membantu pengguna menentukan bidang yang paling sesuai.

User:

> "Aku lebih tertarik AI karena pengen belajar machine learning."

### Goal

> **Learn AI and Machine Learning**

### Action Plan

```text
1. Learn Python fundamentals
2. Learn basic mathematics
3. Learn machine learning concepts
4. Build a simple machine learning project
```

### What Should I Do Next?

> **Start with Python fundamentals for 30 minutes.**

### Progress

Pengguna menyelesaikan langkah pertama dan melanjutkan ke langkah berikutnya.

## 4. Core Flow Summary

```text
Confused
   ↓
Understand
   ↓
Clarify
   ↓
Goal
   ↓
Plan
   ↓
Next Step
   ↓
Progress
```

**Core principle:**

> NextStep membantu pengguna bergerak dari "Saya bingung mau melakukan apa" menjadi "Saya tahu apa yang harus saya lakukan sekarang."
